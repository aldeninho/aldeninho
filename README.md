## 🚀 Featured Projects

### 📦 Olist Delivery Operations Performance
`PostgreSQL` `Python` `Excel` `Power BI`

Analyzes **99,441 real Brazilian e-commerce orders** to find where delivery performance breaks down — and what it costs.

- Defined delivery KPIs in PostgreSQL (CTEs) and Python: found an **8.1% SLA breach rate** exposing **R$1.16M** in order value
- Late orders average **2.57 vs 4.29** review scores (**1.73-point gap**); flagged **RJ, BA, CE** as priority states
- Cross-state routes are **~50% more likely** to be late; shipped an 8-tab Excel workbook and a 3-page Power BI dashboard (DAX)

👉 [Repository](https://github.com/aldeninho/olist-delivery-operations-performance)

### 📊 Olist Customer & Product Analytics
`DuckDB SQL` `Python` `Streamlit`

Retention, churn, LTV, and delivery-impact analysis on **~100K real orders**.

- Ran **8 SQL analyses** with **8/8 automated data-quality checks** passing
- Discovered a **~3.1% repeat-purchase rate**; São Paulo alone drives **R$6.0M of R$16.0M** in revenue
- Welch t-test (**p<0.001, Cohen's d 1.47**) links late delivery to lower review scores; built a multi-page Streamlit dashboard

👉 [Repository](https://github.com/aldeninho/olist-product-analytics)

### 💹 E-commerce Sales & Customer Revenue Analytics
`SQL` `Power BI DAX` `Excel`

Revenue, profitability, and customer analytics on a **star-schema** model (5,200 orders).

- Built a star-schema SQLite model with DAX measures — **Furniture & Electronics = 73.5% of revenue**
- **Revenue attainment 96.1%** but **profit attainment only 80.2%** — growth is less profitable than planned
- Delivered **RFM segmentation**, cohort retention, and returns/cancellation loss analysis, reconciled across SQL, Excel, and DAX

👉 [Repository](https://github.com/aldeninho/ecommerce-sales-analytics)
